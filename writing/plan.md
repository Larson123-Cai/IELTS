# Writing — micro plan

Fits [weekly-plan.md](../weekly-plan.md). This skill moves slowest. **Rewrite on Friday.**

## Each write-micro (20–25 minutes)

Choose one:

- **Sentence set:** 4–6 sentences on the same idea (cause / example / result)
- **PEEL paragraph:** Point → Explain → Example → Link (80–120 words)
- **Timed short:** 120–180 words, one opinion, two reasons

## Week shape

| Day | Task |
|---|---|
| Mon | new short piece (same prompt is allowed) |
| Wed | paragraph or outline: stance + 2 reasons + 1 example each |
| Fri | rewrite Monday **or** Wednesday using at most 3 fixes |

## PEEL (use until band 6.5 is stable)

1. **Point:** one claim
2. **Explain:** why that claim is true
3. **Example:** a scene a stranger can picture (not “people should”)
4. **Link:** back to the question in one line

## By phase

| Phase | Focus |
|---|---|
| A–B | one idea per paragraph; concrete example; basic tense |
| C | Task 2 full shape (intro / 2 body / conclusion); start Task 1 |
| D–E | hedging (*tend to, in some cases*); precise verbs; less translation |

## After each piece

Log 3 errors in `errors.md`. Add usable chunks to `vocab.md`. Do not collect 20 new words from one paragraph.
