# Section 1–4 打法

## Section 1：日常对话（表格 / 笔记 / 填空）

**场景：** 租房、报名、预约、投诉、旅行登记。

**你要赢的点：**

- 名字拼写、电话、邮编、日期、价格一次对。
- 词数限制：`NO MORE THAN TWO WORDS AND/OR A NUMBER` 必须先读。
- 单复数按音频，不按中文习惯补 s。

**听前 30 秒：**

1. 扫表头，知道每一列是什么。
2. 空格预判词性。
3. 圈出容易被替换的词（*cost / location / start date*）。

**日常迁移：** 预约诊所、改订餐厅、报家庭住址。这些场景的口语块直接能用在生活里。

## Section 2：日常独白（设施、活动、地图）

**场景：** 导游、校园介绍、活动须知、安全说明。

**你要赢的点：**

- 地图题：起点 + 路线顺序。
- 规则类信息：开放时间、禁止事项、必须携带。
- 态度不重要，事实重要。

**听前：** 地图先找 *You are here*；非地图题先看选项差异，而不是整句翻译。

## Section 3：学术讨论（2–4 人）

**场景：** 学生和导师、小组做 presentation、讨论实验。

**你要赢的点：**

- 谁的观点：*I thought / she reckons / the tutor suggested*
- 态度词：*sceptical / keen / reluctant / convinced*
- 最终方案常常在后三分之一才出现。

**策略：**

- 选择/匹配：选项先缩写。
- 两人同时说话时，抓 *but / however / instead* 后的内容。
- 题目顺序仍大体按音频顺序，丢题就立刻放弃回追下一题。

**日常迁移：** 会议里「先反对、再给替代方案」的听法，和这一部分完全同构。

## Section 4：学术讲座（笔记填空为主）

**场景：** 单一讲者，主题学术，例子多。

**你要赢的点：**

- 结构感：引言 → 分点 → 例子 → 小结。
- 空格多为主题词、名词短语、数字、专有名词。
- 拼写必须像阅读词汇一样准。

**策略：**

- 预判词性后，眼睛盯当前空和下一个空，形成「双空窗口」。
- 听到举例（*for instance*）先别慌，例子结束后会回收考点。
- 专有名词按拼读规则大胆写，不要空着。

## 全卷节奏

| 时间 | 动作 |
| --- | --- |
| 每 Section 开始前 | 抢读题，预判，划关键词 |
| 音频开始 | 眼睛在当前题，余光看下一题 |
| 漏题 | 立刻放下，用下一题关键词重新挂钩 |
| 全部结束后 | 检查拼写、复数、词数，不改「不确定但符合预判」的答案 |

雅思听力没有额外誊写时间（机考更是直接进答案）。平时训练就按「听完即最终答案」来，不要养成先草写再腾时间抄的习惯。
