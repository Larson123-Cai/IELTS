# 第 0 步：自我诊断（先做这一份）

先不要刷整套。用 **1 套官方真题 Listening**（Cambridge IELTS 任一较新套题）做诊断，规则如下：

- 只听一遍，按考试节奏做完 40 题。
- 不暂停、不回放、不看原文。
- 做完立刻对答案，再听第二遍，把「为什么错」写进错题本。

## 1. 分数怎么看

| 正确题数 | 大约 Band | 接下来的主攻 |
| --- | --- | --- |
| 16–22 | 5.0–5.5 | 基础声音：数字、拼写、连读、Section 1/2 |
| 23–29 | 6.0–6.5 | 同义替换、干扰项、地图、Section 3 |
| 30–35 | 7.0–7.5 | 讲座结构、多选题、细节密度 |
| 36+ | 8.0+ | 维持手感 + 口音广度 + 日常真实语速 |

目标先选一个，不要同时追两个：

- **应试目标**：下一次模考 Section 合计提升 4–6 题。
- **日常目标**：能跟上英/澳日常对话里的弱读和省略。

## 2. 错因分类（比分数更重要）

把 40 题每道错题标成 **一个主因**（只能选一个）：

| 代码 | 错因 | 典型表现 |
| --- | --- | --- |
| A | 没听见声音 | 连读、弱读、吞音，词其实认识 |
| B | 听见了但不认识 | 词汇/拼写缺口 |
| C | 被同义替换绕过 | 题干是 *book in advance*，音频说 *reserve beforehand* |
| D | 被更正信息带跑 | 先说 £30，后来说 *sorry, 35* |
| E | 定位丢了 | 听到后面才发现已经过题 |
| F | 格式/指令错 | 超词数、单复数、大小写习惯、数字单位 |
| G | 地图/流程方向错 | left/right、opposite、beside 搞反 |
| H | 多选题/匹配题逻辑错 | 选项都像，没抓住限定词 |

统计各代码数量。数量最多的 2 类，就是未来 2 周只打的靶。

## 3. 分 Section 体检

听完诊断套，填这张表：

| Section | 正确/10 | 最容易空的题型 | 最怕的声音 |
| --- | --- | --- | --- |
| 1 日常对话 |  | 填空 / 表格 / 拼写 | 数字、地址、电话 |
| 2 日常独白 |  | 地图 / 选择 / 流程 | 指路、设施介绍 |
| 3 学术讨论 |  | 匹配 / 多选 | 两人同时说话、态度词 |
| 4 讲座 |  | 笔记填空 | 语速、举例、转折 |

## 4. 日常听力自测（1 天内做完）

选 **1 段 2–3 分钟** 英/澳日常对话（播客或短视频），只听一遍后回答：

1. 两人在商量什么？
2. 最终决定是什么？
3. 有没有纠正、犹豫、改口？
4. 你能写出 5 个听到的口语块（chunks）吗？例如 *I'm easy either way*、*That works for me*。

如果 1–3 题答不全，日常线先做「精听 + 跟读」，不要先追求泛听时长。
