# Section 1–4 打法

## Section 1：日常对话（表格 / 笔记 / 填空）

场景：租房、报名、预约、投诉、旅行登记。

要赢的点：名字拼写、电话、邮编、日期、价格一次对；先读词数限制；单复数按音频。

听前 30 秒：扫表头 → 预判词性 → 圈出易被替换的词（*cost / location / start date*）。

日常迁移：预约诊所、改订餐厅、报家庭住址。这些 chunks 同时供 Speaking 用。

## Section 2：日常独白（设施、活动、地图）

场景：导游、校园介绍、活动须知、安全说明。

要赢的点：地图起点 + 路线；开放时间、禁止事项、必须携带。态度不重要，事实重要。

听前：地图先找 *You are here*；非地图先看选项差异。

## Section 3：学术讨论（2–4 人）

场景：学生和导师、小组 presentation、讨论实验。

要赢的点：谁的观点；态度词 *sceptical / keen / reluctant / convinced*；最终方案常在后三分之一。

策略：选项先缩写；两人同时说时抓 *but / however / instead* 之后；丢题立刻挂钩下一题。

日常迁移：会议里「先反对、再给替代方案」，和 Writing 让步句同构。

## Section 4：学术讲座（笔记填空为主）

要赢的点：引言 → 分点 → 例子 → 小结；空格多为主题词、名词短语、数字、专有名词。

策略：预判词性后盯「当前空 + 下一个空」；听到 *for instance* 先别慌，例子结束后回收考点；专有名词按拼读大胆写，不要空着。

## 全卷节奏

| 时间 | 动作 |
| --- | --- |
| 每 Section 开始前 | 抢读题，预判，划关键词 |
| 音频开始 | 眼睛在当前题，余光看下一题 |
| 漏题 | 立刻放下，用下一题关键词重新挂钩 |
| 全部结束后 | 检查拼写、复数、词数；不改「不确定但符合预判」的答案 |

机考没有额外誊写时间。平时按「听完即最终答案」训练。
