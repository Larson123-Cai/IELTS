# 听力 × 写作 连动

两个对话框是同一位私教体系的两条线，不是两套互不相干的课程。

## 0. 四份共享文件（不要各写一份）

仓库根目录这 4 个文件由 Writing 维护结构，Listening / Reading / Speaking 共用同一份：

- `PROFILE.md` — 目标 7.5、当前约 band 5、每轮最多纠 3 处
- `vocab.md` — 唯一词汇账
- `errors.md` — 唯一跨技能错法账
- `weekly-plan.md` — 本周四项清单（含 Listening: 1 short audio; shadow 3 sentences）

本对话只往 `vocab.md` / `errors.md` **追加行**，或勾选 `weekly-plan.md` 里已有的 Listening 项。不要改表头、不要把 weekly-plan 改成听力专版。

## 1. 同一周次

Writing 的 Week n 和 Listening 的 Week n 对齐。第 0 周两边都先诊断，不要一边已经 Week 3、另一边还没摸底。

| 周 | Writing 主线 | Listening 主线 | 共用的语言点 |
| --- | --- | --- | --- |
| 0 | 作文诊断 | 真题诊断 + 错因 A–H | 对照共享 `PROFILE.md`（7.5 / 约 band 5）；考试日期口头告诉两边 |
| 1 | 一段一事、具体例子 | 看题预判 + Section 1 | 预约/改期/因果链：听得懂，才能写得清 |
| 2 | Agree / Disagree | 数字、拼写、改口 | *actually / I mean* 后的最终信息 = 写作里的立场要落在最终判断 |
| 3 | 衔接，少堆连接词 | 连读、弱读 | 弱读虚词 (*this / such / these*) 既是听力坑，也是写作粘句材料 |
| 4 | Task 1 图表 | 同义替换 | 上升下降、占比、对比：听讲座/图表解说 ↔ 写 overview |
| 5 | Discussion / 利弊 | 地图、多选、匹配 | 限定词 *only / mainly*；两边论证要对得上限定 |
| 6 | 语法精度 | Section 3 讨论与态度 | *I'm not convinced / that could work* → 让步句 |
| 7 | Problem–Solution | Section 4 讲座结构 | 定义句、分点路标、方案必须对上问题 |
| 8 | 模考 + 禁词表 | 整套计时 + 查漏 | 个人禁词/禁听错点合并进 `errors.md` |

## 2. 一天里怎么排（避免两项满负荷相加）

Writing 默认约 5–7 小时/周，Listening 默认 45–55 分钟/天。两项都做满会到 10 小时以上。按时间选一档：

| 每周总时间 | 怎么排 |
| --- | --- |
| ≥ 10 小时 | 听力日课 + 写作日课都按原表 |
| 6–9 小时 | 听力走 A 筑基（45 分钟）；写作只保底：周四提纲 + 周五成篇 + 周六重写 |
| ≤ 5 小时 | **隔天轮换**：一三五听力精听/题型，二四六写作提纲/成篇/重写；周日共用词汇账 |

推荐顺序：先听力、后写作。耳朵清的时候听；写作用「今天听过的搭配」造句。

## 3. 词汇只记一本

不要听力一本、写作一本。

- 听力跟读出来的 chunks → `vocab.md`，Source 写 `L-W1` 这种
- 写作本周 8–10 个搭配 → 同一张表，Source 写 `W-W1`
- 能听又能写的优先留：例如 *book in advance*、*a noticeable increase in*、*I'm not convinced*

Writing 周日的「词汇账」= 把本周 `vocab.md` 新行各造 1 句。听力周日复盘时，把还跟读不利索的 chunk 标成「否」，下周课前 2 分钟重听。

## 4. 作业发到哪

| 内容 | 对话框 |
| --- | --- |
| 听力对答案、错句、我听成了什么 | **Listening（这里）** |
| Task 1 / Task 2 / 日常短写 | **Writing** |
| 某个搭配既出现在听力又想用进作文 | 先发听力对话，我会写入 `vocab.md`，并告诉你写作那周怎么用 |

批改规则两边相同：每次最多 3 个优先问题；少鼓励；中文讲解、英文例句。
