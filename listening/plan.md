# Listening — micro plan

Fits [weekly-plan.md](../weekly-plan.md). Default block: **15–20 minutes**.

## Each commute block

1. Preview 30 seconds: names, numbers, places
2. Listen once without pausing
3. Shadow **3 sentences** out loud
4. Write 1 missed word or chunk into `vocab.md`

Do not start a new audio if yesterday’s 3 sentences are still muddy.

## Week shape

| Day | Block |
|---|---|
| Mon–Fri | commute audio (same episode is OK for 2 days) |
| Sat | 1 exam section **or** 10–15 exam questions |
| Sun | light replay of the week’s hardest 60 seconds |

## By phase

| Phase | Focus |
|---|---|
| A–B | Section 1–2; numbers; spelling; *sorry / actually / I mean* |
| C | Section 3 discussion; synonym trap |
| D–E | Section 4; notes; one-accent-at-a-time (UK then AU) |

## Output to keep

- 3 shadow sentences / day
- Saturday: score + 5 error words (spelling, plural, or not heard)
