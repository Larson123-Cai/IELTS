# 第 0 周诊断作业

目的：看清你卡在声音、替换、定位，还是格式。不要暂停、不要回放、不要看原文。词典查单词可以，但第一遍不要查。

交作业时请附上：材料名（Cambridge 哪一本哪一套）、实际用时、目标分（若有）。

Writing 的诊断作文请发到 **Writing 对话框**。

---

## 作业 A · 完整 Listening（必做）

**Time: 约 30 分钟音频 + 对答案。一套 40 题，只听一遍。**

用 **Cambridge IELTS** 较新的任意一套 Listening。

做完立刻对答案，再听第二遍，只盯错题，把主因标成 **一个** 代码：

| 代码 | 错因 | 典型表现 |
| --- | --- | --- |
| A | 没听见声音 | 连读、弱读、吞音，词其实认识 |
| B | 听见了但不认识 | 词汇 / 拼写缺口 |
| C | 被同义替换绕过 | 题干 *book in advance*，音频 *reserve beforehand* |
| D | 被更正信息带跑 | 先说 £30，后来说 *sorry, 35* |
| E | 定位丢了 | 听到后面才发现已经过题 |
| F | 格式 / 指令错 | 超词数、单复数、单位 |
| G | 地图 / 方向错 | left/right、opposite 搞反 |
| H | 多选 / 匹配逻辑错 | 选项都像，没抓住限定词 |

数量最多的 2 类 = 未来 2 周只打的靶。

### 分 Section 体检

| Section | 正确/10 | 最容易空的题型 | 最怕的声音 |
| --- | --- | --- | --- |
| 1 日常对话 |  | 填空 / 表格 / 拼写 | 数字、地址、电话 |
| 2 日常独白 |  | 地图 / 选择 / 流程 | 指路、设施 |
| 3 学术讨论 |  | 匹配 / 多选 | 两人同时说、态度词 |
| 4 讲座 |  | 笔记填空 | 语速、举例、转折 |

## 作业 B · 日常 3 分钟（必做）

选 **1 段 2–3 分钟** 英/澳日常对话（播客或短视频），只听一遍后用英语或中文回答：

1. 两人在商量什么？
2. 最终决定是什么？
3. 有没有纠正、犹豫、改口？
4. 写出 5 个听到的口语块（chunks），例如 *I'm easy either way*、*That works for me*。

如果 1–3 题答不全，日常线先走精听 + 跟读，不要先堆泛听时长。
