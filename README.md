# IELTS Listening 私教课

目标：提高英语听力，覆盖 **雅思听力应试** 与 **日常口语表达理解**。

你是学员，我是英语私教。本仓库是 Listening 专线的学习手册：先诊断，再按技能拆解，再按周推进。

## 怎么用这份计划

1. 先做 [自我诊断](plan/00-self-assessment.md)，知道自己卡在哪一类题、哪一类声音。
2. 按 [总计划](plan/STUDY_PLAN.md) 执行 8 周主线。
3. 每天只走 [每日流程](plan/DAILY_ROUTINE.md)，不要一次堆太多材料。
4. 错题一律记进 [错题本](templates/error-log.md)。
5. 把当天听错的句子、听成了什么、正确答案发给我，我会按句子纠音、拆连读、补同义替换。

## 和私教怎么配合

每次练习后，尽量按这个格式发给我：

```text
今天练了：Section X / 日常材料名
错了哪些题：题号 + 我写的答案 + 正确答案
我实际听到的：……
我不确定的词/音：……
想练的表达：……
```

我会回：正确听法、连读拆解、同义替换、以及明天只练哪 1 个点。
