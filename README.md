# IELTS Writing 私教

这个仓库是你的**英语写作私教工作区**（偏雅思 Writing + 日常表达）。

## 怎么跟我练

1. 直接把作文/段落发给我（中英都可夹杂说明）。
2. 我会按雅思四项给你反馈：
   - **TR / TA**：有没有回答题目、立场清不清晰、论证够不够具体
   - **CC**：段落是否一条主线、衔接是否自然
   - **LR**：用词是否准确、是否像“翻译腔”
   - **GRA**：语法错误、句式是否够用且可控
3. 每次反馈固定包含：预估分数、主要问题、示范改写、下一份作业。
4. 完整学习计划见 [`LEARNING_PLAN.md`](./LEARNING_PLAN.md)。
5. 本周先做 [`assignments/week-00-diagnostic.md`](./assignments/week-00-diagnostic.md)。
