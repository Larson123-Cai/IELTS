# IELTS 私教工作区

同一位学员、同一个目标（约 **band 5 → 7.5**），四项技能拆成四个对话框，材料都落在这个仓库。

| 对话框 | 目录 | 现在做什么 |
| --- | --- | --- |
| **Listening**（本对话） | [`listening/`](./listening/README.md) | 第 0 周听力诊断 |
| **Writing** | `writing/`（Writing 对话框同步） | 第 0 周作文诊断 |
| Reading | `reading/` | 阅读对话框跟练 |
| Speaking | `speaking/` | 口语对话框跟练 |

共享档案（四项都会改）：

| 文件 | 用途 |
| --- | --- |
| [`PROFILE.md`](./PROFILE.md) | 目标分、规则、考试信息 |
| [`vocab.md`](./vocab.md) | 听力 chunks + 写作搭配，共用一本 |
| [`errors.md`](./errors.md) | 跨技能反复出现的错法 |
| [`weekly-plan.md`](./weekly-plan.md) | 本周四项日历，避免两项各练满负荷 |

听力专线入口：[`listening/README.md`](./listening/README.md)。
