# 雅思 / 日常阅读 · 8 周学习计划

> 定位：你是学习者，我是 Reading 私教。目标不是“刷完剑桥就完了”，而是练成习惯：**先定位，再改写，再决定**。分数是这个习惯的副产品。
>
> 周主题与 Writing 私教对齐。同一周两边碰到同一类文本（观点、利弊、图表、问题解决），词和结构可以互相用。

## 0. 先定起点

多数中文母语读者卡在同一类问题上：

- 整篇逐句翻译，时间不够，定位也慢
- True / False / Not Given 靠印象，不靠原文限制
- 认识单词，对不上题目里的同义替换
- 长句一慌，主谓被从句淹没

**本计划按 PROFILE：目标 7.5，当前约 band 5。** 第 0 周诊断后，放进两条轨道之一：

| 轨道 | 适合 | 重点 |
| --- | --- | --- |
| **A 打地基** | 预估 5.0–6.0 | 定位、段落主旨、TFNG 纪律、能拆长句 |
| **B 冲 7.5** | 预估 6.0–6.5 | 同义替换、细节陷阱、限时三篇、把阅读短语送进写作 |

考试日期随时补给我，计划按截止日期压缩。

## 1. 我们怎么配合

每周固定闭环：

```
一篇精读（段落功能 + 5 个短语）→ 一种题型微操 → 限时做题 → 我批改错因 → 你重做错题
```

**重做错题比换新题更涨分。** 同一篇改到你能讲出“答案在哪一句、题目怎么改写的”，再换篇。

你每次交作业，尽量带这四行（没有也没关系）：

- 用时：
- 哪一类题最耗时：
- 你自己觉得错在：定位 / 词汇 / 推理过度 / 时间
- 要我重点盯：TFNG / 匹配 / 填空 / 主旨

我每次反馈会给你：

1. 预估阅读段位（教练判断，不是官方分）
2. 最多 3 个优先问题
3. 原文 → 题目 的同义替换示范（2–4 组）
4. 下一份作业（针对本周弱项）
5. 3 个可立刻用的表达（阅读里抠出来的，写作/口语也能用）

## 2. 每周节奏（约 4–6 小时，可压缩到 3 小时）

| 日 | 时长 | 做什么 |
| --- | --- | --- |
| 一 | 40 分钟 | 精读 1 段：主旨一句 + 5 个短语 + 拆 1 个长句 |
| 二 | 40 分钟 | 题型微操：只练一种（TFNG / 匹配 / 填空） |
| 三 | 30 分钟 | **日常表达**：读一段非考场短文（邮件、新闻导语、说明），口头用英语复述 |
| 四 | 40 分钟 | 扫读定位：只找数字、人名、专有名词，不求读懂全篇 |
| 五 | 60 分钟 | 限时 1 篇雅思风格文章（约 20 分钟）+ 对答案 |
| 六 | 40 分钟 | 按我的错因 **重做错题**，把短语写入 `notes/phrases.md` |
| 日 | 20 分钟 | 把本周 5–8 个短语同步到根目录 `vocab.md`，各造 1 句（给 Writing 用） |

没有整块时间时，保底三件事：**周一精读 + 周五限时 + 周六错题。** 这也覆盖共享 `weekly-plan.md` 里的 Reading 项。

## 3. 八周内容（与 Writing 对齐）

### 第 0 周 · 诊断（现在就做）

作业见 `assignments/week-00-diagnostic.md`。文章主题与 Writing 第 0 周一致：**公共卫生 / 运动设施**，方便两边共用词汇。

交完后我会告诉你：轨道 A/B、前三周最该练哪种题、以及你是“读太慢”还是“读完乱猜”。

### 第 1 周 · 把一段读清楚

对应 Writing：主题句 → 解释 → 例子。

- 每段只问：这段在**干什么**（下定义 / 给例子 / 让步 / 对比）
- 禁止从第二句开始翻译；先找主题句
- 日常：读一段产品说明或通知，用一句英语说出它要你做什么

过关标准：给你一篇 4 段短文，你能用中文或英文标出每段功能，且不靠逐句翻译。

### 第 2 周 · 观点类文本（Agree / Disagree）

对应 Writing：先定立场。

- 抓作者态度：hedging（`tend to`, `it is unlikely that`）也是立场
- 分清 **作者观点** vs **文中他人观点**
- 练 Yes / No / Not Given（观点题，不是事实题）
- 日常：读一条短评，用英语说作者站哪边、依据是什么

过关标准：能指出作者最终站哪边；不会把引用的反方意见当成作者本人。

### 第 3 周 · 衔接：跟着指代走

对应 Writing：少堆 `Moreover`，用 `this approach` 粘句子。

- 圈出 `this / these / such / the latter`
- 问：它到底指前面哪一块
- 匹配题（人名—观点、信息—段落）靠指代，不靠同词重复
- 日常：把写作里一段话的指代链读出来，检查你自己写的能否被追踪

过关标准：删掉所有明显连接词后，你仍能说出句子之间的关系。

### 第 4 周 · 数字、比较、概述

对应 Writing Task 1。

- 扫读：最大/最小、交叉、反常，不要每个数字都读
- 表格/流程说明类填空：词性必须对（名词/动词/数字）
- 注意单位和比较对象（`higher than` 比的是谁）
- 日常：读一段公司或城市数据说明，用两句英语做 overview

过关标准：填空拼写和词性正确；overview 只抓 1–2 个最明显特征。

### 第 5 周 · 讨论 / 利弊类长文

对应 Writing：两边都要说到位。

- 一边一段时，两边的证据重量往往不同——阅读题会考“哪边证据更强”
- Matching headings：标题是段落功能，不是某句原词
- 小心绝对词：`always / only / all` 经常把 True 变成 False
- 日常：比较两种学习方式的短文，用英语各给一个具体例子

过关标准：heading 匹配不靠原词；能说出某段是利、弊，还是让步。

### 第 6 周 · 长句 + 同义替换

对应 Writing：先写对，再写长。

- 拆句：找出主谓，把从句摘掉
- 建立你的替换账本：`improve public health` ≈ `reduce rates of illness`
- Summary completion：先看摘要结构，再回原文
- 日常：把本周 Writing 范文的 3 句改写成更短的口语版（读懂复杂句的反向练习）

过关标准：遇到 30+ 词的句子，能在 30 秒内说出主干。

### 第 7 周 · Problem–Solution 与双问题文本

对应 Writing 第 7 周。

- 问题要具体到谁、在什么情境
- 方案必须对上问题；阅读题常考“该方案解决的是哪一个问题”
- 分类题 / 多选题：先排除明显相反的选项
- 日常：读一份“问题说明 + 建议”（学校、产品、社区），用英语复述一对问题—方案

过关标准：问题和方案一一对应；不会把背景当原因。

### 第 8 周 · 模考 + 个性弱项

- 一次完整 Reading：3 篇，60 分钟
- 对照错因看板，只打最弱的一种题型 3 天
- 把本周短语交给 Writing / Speaking 使用
- 输出：一份属于你的考试顺序（先哪篇、哪种题先做）

过关标准：限时能做完；TFNG 不再靠印象；错题能讲出替换链。

## 4. 日常表达这条线（每周都有）

雅思阅读全对，日常仍可能读不懂邮件。所以每周至少 1 段非考场文字：

- 邮件：请求、道歉、改期
- 说明：怎么预约、怎么投诉
- 短评：一条新闻的导语 + 你的一句反应

要求：

- 从中抽出 **1 个句型 + 2 个搭配**
- 用英语口头复述，别扭的地方标出来发给我

## 5. 词汇怎么记（不要背阅读机经词表）

每周只收 5–8 个，必须满足：

- 你能在原文中指到它
- 你能不看中文说出英文意思
- 你能用它造一个和 **本周 Writing 题目有关** 的句子

优先记搭配：

- `have little effect on`
- `other measures are required`
- `a noticeable decline in`
- `it is unrealistic to expect...`

禁止为了“高级”而收的孤词。Writing 禁用的 `plethora / myriad / double-edged sword` 这里也不收。

## 6. 每两周检查一次

1. 还在逐句翻译吗？
2. TFNG 是原文限制，还是你在脑补？
3. 错题能不能指出那组同义替换？
4. 短语有没有进 `vocab.md`，Writing 有没有用上？
5. 限时是超时，还是做完了但错一堆？

连续两篇同一题型拖后腿 → 下一周只打这一项，暂停换新题型。
