# Reading — micro plan

Fits [weekly-plan.md](../weekly-plan.md). Default block: **20 minutes**. One paragraph beats a skipped full test.

## Each read-micro

1. Read one paragraph (or 150–250 words)
2. Write the main idea in **one English sentence**
3. Pick 3 phrases (not 15 words)
4. Put phrases in `vocab.md` with your own example sentence

## Week shape

| Day | Task |
|---|---|
| Tue | paragraph + main idea |
| Thu | next paragraph of the same article, or 1 question type |
| Sat/Sun | optional: 1 Cambridge passage (Phase C+) |

## By phase

| Phase | Focus |
|---|---|
| A–B | main idea; pronoun reference; unknown phrases in context |
| C | headings; True/False/Not Given: *not given* means not in the text |
| D–E | speed: 20 minutes / passage; paraphrase before matching |

## Ban

Do not translate the whole paragraph into Chinese. One-sentence main idea + 3 chunks is the product.
